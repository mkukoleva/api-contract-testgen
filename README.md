# api-contract-testgen

Прототип инструмента тестирования микросервисов по API-контракту.
Цель — генерация запускаемых pytest-тестов (штатный сценарий,
граничные случаи, обработка ошибок) с помощью LLM и оценка их качества.

Сейчас агент читает контракт, вызывает микросервис Schemathesis и генерирует
текстовые user story. Демонстрационная проверка API и проверка user story
остаются заглушками.

Для pytest-runner реализованы этапы 1–5: интерфейс, отдельный стенд Catalogue,
запуск сохранённых тестов в Docker, доступ только к TCP-адресу и порту API,
проверка синтаксиса и сбор pytest в изоляции. Runner собирает результаты,
обрабатывает ошибки и таймаут, удаляет контейнер; к LLM он не обращается.
Результаты каждого запуска сохраняются в JSON и Markdown в отдельном каталоге
с датой/временем UTC и уникальным ID (этап 6). Метрики runner не рассчитывает;
в отчёте для них оставлено `metrics: null`. Запускаемость сгенерированных
тестов (Runnability) рассчитывает конвейер генерации: знаменатель — статический
перечень ожидаемых тестов от генератора, числитель — реально выполнившиеся
тела тестов; результат сохраняется в `generation-report.json`/`.md` рядом
с попытками прогона. Подключение к генератору — следующий этап.

- [Установка, запуск агента и проверки](prototype/ReadMe.md).
- [Соглашение о pytest-runner для команды](docs/adr/0002-pytest-runner-contract.md).
- [Сохранение сгенерированных тестов](docs/adr/0003-generated-tests-storage.md).

## Проверка одной командой

Из корня репозитория (подробнее — в [prototype/ReadMe.md](prototype/ReadMe.md)):

```bash
# Полный цикл: окружение -> стенд Catalogue -> готовность -> pytest ->
# сохранённые наборы через runner -> отчёты -> очистка. LLM не вызывается.
uv run --project prototype --locked --no-sync python tools/verify.py

# Быстрый режим без стенда и Docker (юнит-тесты):
uv run --project prototype --locked --no-sync python tools/verify.py --offline --skip-runner-set
```

Один раз до первого запуска: `uv sync --locked` в `prototype/` и сборка образа
runner (`docker build -t api-contract-pytest-runner:step5 prototype/src/prototype/service_tools/runner`).
Повторные запуски не требуют правки файлов, ключей LLM и установки
зависимостей. Обычный CI (`.github/workflows/ci.yml`) использует сохранённые
наборы тестов `benchmark/pytest-runner/saved-sets/` без платной генерации.
