# ADR 0001 — Структура репозитория

Статус: принят.

## Решение
Репозиторий разбит на слои: prototype/ (parser, llm, postprocess,
runner, evaluate, tests), docs/ (adr, reports), benchmark/
(демо-микросервисы), .github/workflows/ (CI).

## Почему
Модули независимы — команда работает параллельно; решения и отчёты
отделены от кода; CI проверяет каждый pull request.

## Последствия
- Параллельная разработка без конфликтов.
- Пустые папки держим через .gitkeep.
- Работа только через pull request, прямые коммиты в main запрещены.
