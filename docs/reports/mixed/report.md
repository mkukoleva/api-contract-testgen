# [Ocntafic](https://github.com/Octrafic/octrafic-cli)
## Описание
LLM агент, который генерирует для конкретного ендпоинта
## плюсы:
- есть возможность запустить обычный тест без LLM
## минусы:
- не может работать с gRPC
- последние обновление 6 месяцев назад
- не удалось запустить агента с локальной моделью из-за того, что не совпадает спецификация
## Использование в проекте
- можно взять как пример чат-агента для написания тестов
- нельзя использовать в качестве инструмента

# [API Test Genie](https://github.com/Andrepereira2001/ApiTestGenie)
## Описание
- LLM инструмент для генерации тестов на typescript
- инструмент из себя представляет Python-скрипт, который передаёт в LLM-модель заранее подготовленный промпт и действия пользователя (добавить товар в корзину, перейти на какую-то страницу) на основе этого модель генерирует тесты
## плюсы:
- нативная поддержка докера
- можно удобно тестировать взаимодействия между сервисами
## минусы:
- ориентирован на REST
- нет системы, которая будет переписывать тесты, которые не проходят
  - при тестировании инструмента у меня возникла проблема с тем, что запрос возвращал 302 (перенаправление), а не 200 из-за чего тест не проходил, хотя всё было правильно
## Использование в проекте
можно взять за основу
  - сделать так, чтобы компания могла сама выбирать модель
  - добавить агента, который будет проверять и перегенерировать тесты, если первый агент допустил ошибку
  - добавить чат, где можно будет описывать действия пользователя, при необходимости
