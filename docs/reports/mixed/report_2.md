## Описание

Тестировался AI-агент на базе локальной LLM (`qwen2.5-coder:1.5b` через Ollama), который по OpenAPI-контракту генерирует исполняемые Gherkin-сценарии (BDD/Cucumber).

---

## Плюсы

- Модель успешно прочитала OpenAPI-контракт и получила из него конкретный эндпоинт.
- Создан синтаксически правильный сценарий с ключевыми словами `Feature`, `Scenario Outline`, `Given`, `When`, `Then`, `And`, `Examples`.
- Сгенерированный сценарий был успешно выполнен через Cucumber (behave).
- Не требует интернета и API-ключей для работы.
- Может понимать запросы на русском языке.

## Минусы

- Не всегда генерирует Gherkin с первого запроса, нужно уточнять.
- Иногда генерирует сценарий не для того эндпоинта, который был указан в запросе.
- Не выполняет HTTP-запросы:Генерирует только сценарии, но не проверяет реальное поведение API.
- Для обработки больших контрактов нужна оперативная память.
- Качество и стабильность генерации напрямую зависят от выбранной LLM.

## Использование в проекте

- Можно взять как основу для демонстрации, чтобы показать принцип автоматической генерации BDD-сценариев из API-контрактов.
- Нельзя использовать как готовый промышленный инструмент без дополнительной доработки (системы точного выбора эндпоинтов, валидации и перегенерации тестов).
